Grid Animation Library

imgタグに class="grid-animation" を追加するだけで、グリッドアニメーション効果が適用されます。

使い方

<!-- 1. JavaScriptを読み込む -->
<script src="grid-animation.js"></script>

<!-- 2. imgタグにクラスを追加 -->
<img src="your-image.jpg" class="grid-animation" alt="画像">

デモ

カスタマイズ

<script>
// 設定をカスタマイズする場合
GridAnimation.config.gridCols = 8;        // 横のグリッド数
GridAnimation.config.gridRows = 6;        // 縦のグリッド数
GridAnimation.config.delayMin = 2;        // 最初の遅延（ミリ秒）
GridAnimation.config.delayMax = 20;       // 最後の遅延（ミリ秒）
GridAnimation.config.reverseNDelay = 200; // 逆N字順の遅延（ミリ秒）
</script>
